# 🎮 Tic-Tac-Toe Game

An interactive two-player Tic-Tac-Toe game built with HTML, CSS and JavaScript.

## ✨ Features

- Two-player gameplay
- Winner detection
- Draw detection
- Reset/New Game
- Sound effects
- Winning animation
- Responsive design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
